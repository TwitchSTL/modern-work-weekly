## Top 5

1. **[Storm-0940 ARTEX agentic AI supply chain campaign targeting M365:](https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/)** {{< cat "Security & Compliance" >}} {{< reason "Patch Now" >}} A nation-state actor (Storm-0940) used an agentic AI tool called ARTEX to accelerate a ConnectWise supply chain compromise, leading to application credential abuse across M365 tenants. Review your ConnectWise integrations, audit app registrations and service principal credentials in Entra ID, and check for anomalous OAuth consent grants. If you run LiteLLM in any AI pipeline, see the separate supply chain compromise writeup this week.

2. **[CVE-2026-105014 Azure Pipelines Remote Code Execution - Critical CVSS 9.1:](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-105014)** {{< cat "Action Required" >}} {{< reason "Patch Now" >}} Command injection in Azure Pipelines allows an unauthenticated attacker to execute code over a network. If your pipelines are internet-exposed or use shared hosted agents, treat this as urgent. Validate your patching posture against this CVE immediately.

3. **[CVE-2026-111497 Brotli decoder buffer overflow in .NET - Critical CVSS 8.1:](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-111497)** {{< cat "Action Required" >}} {{< reason "Patch Now" >}} An out-of-bounds write in .NET's Brotli decoder allows network-based privilege escalation. Any .NET workload processing compressed content from external sources is exposed. Patch .NET runtimes across all managed endpoints and servers.

4. **[Exchange Online EWS retirement - apps are breaking now:](https://techcommunity.microsoft.com/t5/exchange-team-blog/exchange-online-ews-application-stopped-working-do-this/ba-p/4566215)** {{< cat "Collaboration & Productivity" >}} {{< reason "Deadline" >}} EWS is being turned off in Exchange Online and applications are actively failing, including Apple Mail and Calendar on macOS, classic Outlook for Mac, and third-party backup tools. Run the EWS usage report in the Exchange admin center, identify every dependent app in your estate, and get migration to Graph API on the roadmap now.

5. **[Power Platform Admin Plugin for Copilot Cowork - natural language governance:](https://techcommunity.microsoft.com/t5/copilot-studio-blog/introducing-the-power-platform-admin-plugin-in-cowork-agentic/ba-p/4567557)** {{< cat "AI & Copilot" >}} {{< reason "Governance Move" >}} Admins can now query tenant-specific Power Platform data in natural language through Cowork, surfacing things like orphaned assets owned by departed employees without manually correlating multiple admin views. If Power Platform governance is a gap in your environment, this is worth enabling immediately.
