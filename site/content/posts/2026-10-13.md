## Top 5

1. **[Send-from-alias GA in Exchange Online:](https://techcommunity.microsoft.com/t5/exchange-team-blog/sending-from-email-aliases-general-availability/ba-p/4562543)** {{< cat "Collaboration & Productivity" >}} {{< reason "New Capability" >}} Users can now send from any proxy address on their mailbox, not just the primary SMTP address. This closes a long-standing gap that forced workarounds like shared mailboxes or send-as delegation for alias-based identities. Review which mailboxes have proxy addresses that shouldn't be exposed as sender addresses and confirm your DLP/transport rules account for the expanded sender surface.

2. **[Purview DLP policies for Copilot grounding now GA:](https://techcommunity.microsoft.com/t5/microsoft-security-community/protecting-organizations-from-external-email-risks-in-microsoft/ba-p/4562820)** {{< cat "Security & Compliance" >}} {{< reason "Governance Move" >}} Two new Purview DLP policies ship this week: one restricts Copilot from grounding responses in external email (reducing prompt injection risk), and a second blocks sensitive data types from leaking into Copilot's external web search queries. Both are actionable now and address real attack surface created by Copilot's retrieval behavior. If you haven't audited your Copilot DLP posture, these policies are the place to start.

3. **[Project Perception multi-agent security defense GA:](https://www.youtube.com/watch?v=afXHGzGNAtM)** {{< cat "Security & Compliance" >}} {{< reason "New Capability" >}} Microsoft Defender's Project Perception orchestrates red, blue, and green AI agent teams to validate attacker reachability, generate KQL detections, harden posture, and push tested code fixes in minutes. The human-approval checkpoint before agent execution and the MCP plug-in for terminal-based management are the two details worth evaluating for your SOC workflows.

4. **[Windows Update certificate rotation deadline: May and June 2027:](https://techcommunity.microsoft.com/t5/windows-it-pro-blog/prepare-for-windows-update-certificate-rotation-in-2027/ba-p/4562463)** {{< cat "Endpoint & Device Management" >}} {{< reason "Deadline" >}} Certificates used to establish trust with Windows Update servers expire May 17 and June 19, 2027. Devices that haven't been updated before then will lose connectivity to Windows Update. Start identifying devices that are unlikely to receive updates naturally before those dates, particularly offline, air-gapped, or long-deferred endpoints.

5. **[Entra ID Agent ID lifecycle policies now documented:](https://github.com/MicrosoftDocs/entra-docs/commit/4315a4c6037e6e3ba0da0487583a41f70f902ccc)** {{< reason "Governance Move" >}} Microsoft has published new documentation covering lifecycle policies for Entra Agent IDs, including sign-in health investigation for both interactive and autonomous agent sign-ins. As AI agents accumulate Entra identities in your tenant, these policies are the control plane for managing their access lifecycle. Worth reading before your agent footprint grows further.

## Endpoint & Device Management

- **[Prepare for Windows Update certificate rotation in 2027](https://techcommunity.microsoft.com/t5/windows-it-pro-blog/prepare-for-windows-update-certificate-rotation-in-2027/ba-p/4562463)** [GA] - Certificates anchoring trust for Windows Update connections expire May 17 and June 19, 2027; devices that miss the update carrying new certificates will lose Windows Update connectivity entirely. Microsoft is handling this automatically for most managed devices, but you need to identify exceptions: air-gapped endpoints, devices behind strict egress controls, and anything that hasn't taken updates recently. Audit your device population now and plan remediation for outliers.

- **[Remote PC connections in Windows App on Windows now GA](https://techcommunity.microsoft.com/t5/windows-it-pro-blog/remote-pc-connections-in-windows-app-on-windows-is-now-generally/ba-p/4561186)** [GA] - Windows App now supports direct remote PC connections alongside Windows 365, Azure Virtual Desktop, and Dev Box in a single pane, without requiring a work or school account. This is a meaningful change for helpdesk, IT admin, and lab scenarios where you want unified remote access without additional licensing or identity dependencies. Evaluate whether this changes your VPN or remote access tooling decisions.

## AI & Copilot

- **[Dynamics 365 Project Operations: Unify product receipt and item requirement posting](https://www.microsoft.com/microsoft-365/roadmap?id=574123)** [Preview] - A new feature combines purchase order product receipt posting and linked project item requirement consumption into a single atomic transaction, preventing duplicate project postings and rolling back both on error. GA now. If your project delivery teams have standardized task structures, this simplifies templating without the overhead of copying full project records.

- **[Power Apps: Model-driven apps in Business Apps in Work IQ](https://www.microsoft.com/microsoft-365/roadmap?id=571888)** [Preview] {{< emphasis "Apps" >}} - Power Apps model-driven apps surface in Work IQ as Business Apps, accessible via Copilot Studio or the Work IQ MCP with natural-language prompts for listing, reading, creating, updating, and deleting records. - **[Microsoft Power Pages now available in Sweden Central and Italy North](https://www.microsoft.com/en-us/power-platform/blog/power-pages/microsoft-power-pages-is-now-available-in-sweden-central-and-italy-north/)** [GA] - Power Pages is now GA in two additional Azure regions, relevant for organizations with data residency requirements in Sweden or Italy. ## Security & Compliance

- **[Fight AI with AI: Multi-Agent Security Defense (Project Perception)](https://www.youtube.com/watch?v=afXHGzGNAtM)** [GA] {{< emphasis "SecOps" >}} - Project Perception in Microsoft Defender orchestrates red, blue, and green AI agent teams against a specified threat actor profile, confirming attacker-reachable vulnerabilities, deploying KQL detections, hardening posture, and merging tested code fixes. Human approval gates are built in before agents take consequential actions; sessions can be managed from the Defender portal or a terminal via MCP plug-in. Token costs are contained by MAI Cyber Flash, a purpose-built security model. This is the most significant SOC workflow automation Microsoft has shipped to date.

- **[Protecting Organizations from External Email Risks in Microsoft 365 Copilot](https://techcommunity.microsoft.com/t5/microsoft-security-community/protecting-organizations-from-external-email-risks-in-microsoft/ba-p/4562820)** [GA] {{< emphasis "Data" >}} - A new Purview DLP policy lets you restrict Copilot from grounding responses in external or unverified email, reducing cross-prompt injection risk while keeping internal email grounding intact. Configure this in the Purview compliance portal under DLP policies. If Copilot is in production in your tenant, this policy should be in your deployment baseline.

- **[DLP for External Web Search in Microsoft 365 Copilot](https://techcommunity.microsoft.com/t5/microsoft-security-community/why-dlp-for-external-web-search-in-microsoft-365-copilot-matters/ba-p/4562818)** [GA] {{< emphasis "Data" >}} - A complementary Purview DLP policy detects and blocks sensitive data types (credit card numbers, passport numbers, SSNs) from being included in Copilot's external Bing web search queries. Configure alongside the external email grounding policy for a complete Copilot data egress posture. Both policies are available now.

- **[The Microsoft AI and Agent Platform: Securing and Governing Intelligent Agents](https://techcommunity.microsoft.com/t5/microsoft-security-community/the-microsoft-ai-and-agent-platform-securing-and-governing/ba-p/4562204)** [GA] {{< emphasis "AI" >}} - Part 2 of Microsoft's AI and Agent Platform series covers how the security model changes when agents move from answering questions to taking actions: delegated identity, API calls, tool invocations, cross-agent collaboration, and persistent memory all expand the attack surface. Worth assigning to anyone designing or approving agent deployments in your environment.

- **[CISO perspectives on managing vulnerability risks in the age of AI](https://www.microsoft.com/en-us/security/blog/2026/10/06/ciso-perspectives-on-managing-vulnerability-risks-in-the-age-of-ai/)** [GA] - Microsoft's security blog covers how CISOs can apply AI-powered vulnerability management to increase resilience, including prioritization strategies and tooling considerations. Useful context for framing your own vulnerability management roadmap conversations with leadership.
