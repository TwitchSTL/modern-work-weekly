## Top 5

1. **October 2026 Windows updates destabilizing on-prem Exchange Servers:** {{< cat "Collaboration & Productivity" >}} {{< reason "Patch Now" >}} If you applied October Patch Tuesday updates to Exchange Server SE, 2019, or 2016 hosts, check your OWA error logs and mail queue depths now. Reported symptoms include MapiExceptionMdbOffline failures, crawling email queues, and DAG quorum issues. Microsoft has published an incident post with mitigation steps; prioritize this over any other patching work this week.

2. **Microsoft 365 E7 agent insider risk controls GA:** {{< cat "Security & Compliance" >}} {{< reason "Governance Move" >}} Microsoft is framing AI agents as the newest insider threat vector, and E7 plus Project Perception now give admins containment controls that adapt protection continuously as agent behavior evolves. If your org has deployed Copilot agents or third-party agents in M365, review the new E7 capabilities before your next security posture review.

3. **Intune CNAME auto-discovery end of support - January 15, 2027:** {{< cat "Endpoint & Device Management" >}} {{< reason "Deadline" >}} MDM-only Windows enrollment via EnterpriseEnrollment DNS CNAME records stops working in Intune on January 15, 2027. Audit your enrollment flows now and update any user-facing documentation or deployment scripts that rely on CNAME-based discovery before the cutoff.

4. **New Defender for Identity alerts for Entra ID and Active Directory:** {{< cat "Identity & Access" >}} {{< reason "Governance Move" >}} The October update adds new alerts covering suspicious sign-in via Temporary Access Pass and additional Active Directory attack patterns. Review your alert tuning and incident response playbooks to account for the new signal coverage.

5. **Purview auto-labeling troubleshooting playbook published (500K files/day scale):** {{< cat "Security & Compliance" >}} {{< reason "New Capability" >}} Microsoft raised the tenant ceiling for service-side auto-labeling to 500,000 files per day and published a structured field-fix playbook for SharePoint and OneDrive policies. If you run auto-labeling at scale and have unexplained labeling gaps, this playbook replaces the usual trial-and-error troubleshooting cycle.
