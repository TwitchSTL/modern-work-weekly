## Top 5

1. **[EWS Deprecation Is Live in Exchange Online](https://techcommunity.microsoft.com/t5/exchange-team-blog/ews-deprecation-is-here-what-this-means-to-you/ba-p/4561431):** {{< cat "Collaboration & Productivity" >}} {{< reason "Deadline" >}} As of early October 2026, setting `EWSEnabled` to `True` alone no longer keeps EWS working. You must now populate `EWSAllowedAppIDs` with an explicit app allow list or EWS traffic breaks for unlisted apps. Hybrid customers with on-premises mailboxes and cross-org sharing arrangements have additional exposure; review the dedicated hybrid impact post now and plan for the full deprecation timeline running through April 2027.

2. **[Upgrade ExchangeOnlineManagement PowerShell Module to v3.10.1 or newer](https://techcommunity.microsoft.com/t5/exchange-team-blog/action-required-upgrade-exchangeonlinemanagement-powershell/ba-p/4561418):** {{< cat "Collaboration & Productivity" >}} {{< reason "Deadline" >}} Microsoft has hardened the Exchange Online PowerShell authentication flow in v3.10.1, and older module versions will progressively fail to meet future authentication requirements. If your automation or admin scripts run anything below v3.10.1, update now before those sessions start breaking silently.

3. **[CVE-2026-69712 Windows Key Distribution Center Remote Code Execution](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69712):** {{< cat "Action Required" >}} {{< reason "Patch Now" >}} Critical, CVSS 8.8 RCE in the Windows Key Distribution Center. An acknowledgment update surfaced this week, but the vulnerability class (KDC RCE) and severity mean any domain controller exposure warrants immediate patch verification. Confirm your September CU is deployed across all DCs.

4. **[Windows 11 26H2 GA and Intune Security Baseline Available](https://learn.microsoft.com/en-us/intune/device-security/security-baselines/configure-baselines#create-a-profile-for-a-security-baseline):** {{< cat "Endpoint & Device Management" >}} {{< reason "New Capability" >}} Windows 11 version 26H2 is generally available and ships as an enablement package for devices already on 25H2 or 24H2, making adoption low-disruption. The matching Intune security baseline is live now, and the Settings Catalog has day-zero policy support. Existing baseline profiles do not auto-update; create or migrate profiles deliberately.

5. **[Purview Unified Classifiers Experience in Public Preview](https://techcommunity.microsoft.com/t5/microsoft-purview-blog/meet-the-new-microsoft-purview-classifiers-experience-your-admin/ba-p/4561324):** {{< cat "Security & Compliance" >}} {{< reason "Governance Move" >}} The new unified classifiers experience consolidates all Purview classification types into a single admin surface with classified-item counts and policy dependency visibility. This makes it materially safer to modify or retire classifiers without unintended DLP or retention policy gaps. Worth enabling in a test tenant now to map your current classifier sprawl.

## Identity & Access

- **[Every AI Agent Gets a Microsoft Entra ID](https://www.youtube.com/shorts/_9boiyCkNv0)** [GA] {{< emphasis "AI" >}} - Every agent deployed to Microsoft Foundry receives a unique Entra identity with scoped permissions, enabling traceable, auditable agent actions either autonomously or on behalf of a signed-in user in an isolated microVM. This has direct implications for your PIM and Conditional Access policies: agent identities need to be accounted for in your identity governance model just like service principals. Start mapping agent identity patterns now before Foundry adoption scales in your environment.

- **[Beyond Source Code: A Path to the Keys to the Kingdom](https://www.microsoft.com/en-us/security/blog/2026/09/29/beyond-source-code-a-path-to-the-keys-to-kingdom/)** [GA] - Microsoft Threat Intelligence details how Storm-3068 pivoted from a compromised developer identity to broad cloud access, including CI/CD pipelines and cloud infrastructure. If your organization stores credentials in source repositories or grants pipeline service principals broad cloud permissions, this attack chain is directly applicable. Review pipeline identity scopes and rotate any long-lived credentials exposed through code repositories.

- **[Passkeys from External Identity Providers Now Work Across Microsoft Apps](https://techcommunity.microsoft.com/t5/microsoft-entra-blog/sign-in-to-microsoft-apps-with-passkeys-from-external-identity/ba-p/4556448)** [GA] - Microsoft apps including Outlook, Teams, OneDrive, and Office apps on Android, iOS, and managed macOS now support FIDO2 passkeys and security keys issued by external IdPs. Previously, embedded web views blocked this flow for federated users. If your org federates to a third-party IdP and you've been blocked from rolling out phishing-resistant MFA to mobile users, this unblocks that deployment.

- **[Dynamics 365 Commerce: Bulk Item Entry for Store Transactions](https://www.microsoft.com/microsoft-365/roadmap?id=573275)** [GA] - Store Commerce associates can now paste or enter multiple item-quantity pairs in a single bulk-entry dialog rather than scanning items one at a time. Supported delimiters include spaces, commas, tabs, and the `x` character. This is a retail workflow improvement with no admin configuration required.
