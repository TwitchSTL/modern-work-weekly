## Top 5

1. **Purview Retention for Copilot Memory (GA)** {{< cat "Security & Compliance" >}} - Copilot memory items now have full retention and versioning support in Purview Data Lifecycle Management. If your org has Copilot deployed, you need a retention policy for this data; it lives in a hidden Exchange mailbox folder and is now subject to the same compliance controls as other mailbox content.

2. **DSI + Endpoint DLP Integration (Preview)** {{< cat "Security & Compliance" >}} - Data Security Investigations can now be launched directly from endpoint DLP alerts, automatically surfacing the files that triggered those alerts. This cuts triage time significantly for exfiltration scenarios and is worth enabling in preview to build familiarity before GA in September 2026.

3. **Organizational Messages Supports Hybrid-Joined Devices (Preview)** {{< cat "Security & Compliance" >}} - Hybrid-joined devices can now receive Organizational Messages through the Microsoft 365 admin center. If you've been holding off on this channel because of hybrid coverage gaps, that blocker is gone as of this preview.

4. **Purview Data Lifecycle: Copilot Memory Compliance Gap Closed** {{< cat "Security & Compliance" >}} - The GA of retention for Copilot memory is the single most significant compliance posture change for Copilot-enabled tenants this week. Audit your existing DLM policies now to ensure Copilot memory is in scope.

5. **David Weston AMA on Agentic Security** - For teams thinking about AI-driven security operations, the Microsoft Security Community AMA with David Weston (head of Agentic Security at Microsoft) is worth the recording. His team is building the frontier security models and agentic defender systems that will shape how Microsoft's own security tooling evolves.

## Security & Compliance

- **[Reminder: Ask Microsoft Anything with David Weston (8/25 at 8AM PST)](https://techcommunity.microsoft.com/t5/microsoft-security-community/reminder-ask-microsoft-anything-with-david-weston-is-tomorrow-8/ba-p/4549690)** [GA] - David Weston leads Agentic Security at Microsoft, overseeing AI models, autonomous agents, and evaluation systems for defenders. His background spans exploit mitigation, APT research, and security engineering for Windows, Xbox, and Azure OS. If your team is evaluating AI-driven detection or agentic SOC capabilities, the recording from this AMA is worth pulling.

- **[Microsoft Purview: Data Security Investigations - Analyze Files Tied to Endpoint DLP Alerts](https://www.microsoft.com/microsoft-365/roadmap?id=558547)** [Preview] - DSI can now be launched directly from an endpoint DLP alert, automatically gathering the files that triggered the alert for review based on your query parameters (time range, user, endpoint). This removes the manual pivot between alert triage and content investigation that previously slowed down exfiltration response. Preview is available now; GA is targeted for September 2026.

- **[Microsoft 365 Admin Center: Organizational Messages Now Supports Hybrid-Joined Devices](https://www.microsoft.com/microsoft-365/roadmap?id=503564)** [Preview] - Hybrid-joined devices can now receive Organizational Messages, closing the coverage gap that previously limited this channel to cloud-native or Entra-joined endpoints. If your organization operates a hybrid estate and has been waiting on this to standardize employee communications, begin piloting now. GA was targeted for June 2026 and preview has been running since December 2025.

- **[Microsoft Purview: Data Lifecycle Management - Retention for Copilot Memory](https://www.microsoft.com/microsoft-365/roadmap?id=569612)** [GA] - Retention policies can now cover Microsoft 365 Copilot memory items, including saved memories and inferred context stored in a hidden Exchange mailbox folder. This enables versioning of inactive memory items so administrators maintain an audit trail of memory changes even as active memory continues to be managed by the Copilot service. Any tenant with Copilot deployed should review DLM policies immediately to bring this data class into scope.

## Action Required

There are no CVEs or externally-imposed hard deadlines in this week's data. The following items most warrant attention in the next 30 days:

- **Purview Retention for Copilot Memory - Review DLM policies now (GA).** Copilot memory is stored in a hidden Exchange mailbox folder and is now subject to Purview retention. If you have Copilot licensed users, audit your existing retention policies to confirm this data class is covered before an investigation or regulatory inquiry surfaces the gap.

- **DSI + Endpoint DLP Integration - Enable in preview before September GA (Preview, GA: September 2026).** The window to get familiar with Data Security Investigations launched from endpoint DLP alerts is open now. Stand up a test scenario against your endpoint DLP policies so your team can operationalize this workflow at GA without a cold start.

- **Organizational Messages for Hybrid-Joined Devices - Pilot in preview if hybrid coverage was your blocker (Preview).** If hybrid device coverage was the reason you haven't standardized on Organizational Messages as a comms channel, begin your pilot now. GA was originally scoped for June 2026; confirm the updated GA timeline in the roadmap before committing to a rollout schedule.
