## Top 5

1. **CVE-2026-64903: Critical Microsoft Office RCE (CVSS 7.8)** {{< cat "Security & Compliance" >}} - A Critical-severity remote code execution vulnerability in Microsoft Office is in the CVE list this week. Patch status is the priority check: confirm your Office update rings have pushed the fix and verify compliance in Intune or Defender for Endpoint before end of week.

2. **CVE-2026-69836: Critical Entra ID RCE corrected to non-exploited (CVSS 10.0)** {{< cat "Security & Compliance" >}} - MSRC corrected the Exploited flag to No for this CVSS 10.0 Critical Entra ID RCE. The score still demands attention: verify your tenant has the remediation applied and review any prior incident triage you performed based on the earlier exploited status.

3. **CVE-2026-32202: Windows Shell Spoofing confirmed exploited in the wild (CVSS 4.3)** {{< cat "Security & Compliance" >}} - Despite a modest CVSS score, this vulnerability carries cve_exploited: Yes, meaning it is actively being used. Prioritize patching Windows endpoints regardless of the low base score, and check your ASR and Windows Update compliance posture now.

4. **Entra custom branding CSS deprecation begins October 26, 2026** - Custom CSS layout and positioning properties in Entra branded sign-in pages are being retired starting October 26, 2026, with full CSS retirement in 2027. If your tenant uses custom CSS for sign-in branding, audit your configurations now and begin planning the migration to supported alternatives before the October deadline hits.

5. **Exchange EWS retirement: October 2026 phased disablement is approaching** - EWS in Exchange Online begins phased disablement in October 2026 and goes fully dark in April 2027. The Exchange team published field guidance this week on safely testing EWSAllowedAppIDs and a separate post clarifying Free/Busy impact for hybrid and on-premises-to-online org scenarios. If you have not completed your EWS dependency audit, the window is closing fast.

## Identity & Access

- **[Microsoft Entra ID enhances security of branded sign-ins](https://techcommunity.microsoft.com/t5/microsoft-entra-blog/microsoft-entra-id-enhances-security-of-branded-sign-ins/ba-p/4537471)** [GA] - If your tenant relies on custom CSS for sign-in page layout or positioning, you have until October 26, 2026 before Microsoft begins retiring those properties, with full CSS retirement following in 2027. ## Collaboration & Productivity

- **[Help us shape Exchange Server on-premises to different online org Free/Busy after EWS retirement](https://techcommunity.microsoft.com/t5/exchange-team-blog/help-us-shape-exchange-server-on-premises-to-different-online/ba-p/4549691)** [GA] - EWS in Exchange Online enters phased disablement in October 2026 and is fully gone by April 2027, and the Exchange team is now actively soliciting input on how to handle the remaining Free/Busy scenario: Exchange Server on-premises sharing calendar availability with a different Exchange Online organization. Purely on-premises org-to-org and hybrid Free/Busy are not affected, but cross-org scenarios with an online tenant on the other side need attention. Respond to the survey and map your Free/Busy dependencies now.

- **[Notes from the field: testing EWSAllowedAppIDs safely](https://techcommunity.microsoft.com/t5/exchange-team-blog/notes-from-the-field-testing-ewsallowedappids-safely/ba-p/4548568)** [GA] - This field guide from the Exchange team is required reading before you lock down EWS access with EWSAllowedAppIDs. It walks through a controlled positive-and-negative test to confirm the allow list is working as expected, and it calls out the common naming confusion between EWSAllowedAppIDs and EWSBlockedApplicationList, which operate at different layers. Run the test in a non-production tenant first to avoid accidental service disruptions.

- **[Understanding the new 100 GB mailbox entitlement for Microsoft 365 Business suites](https://techcommunity.microsoft.com/t5/exchange-team-blog/understanding-the-new-100-gb-mailbox-entitlement-for-microsoft/ba-p/4548243)** [GA] - Microsoft 365 Business Basic, Standard, and Premium users now get a supported primary mailbox size of up to 100 GB, up from 50 GB. The Exchange team explains how the additional storage is provisioned and what admins need to understand about the delivery mechanism. No immediate admin action is required, but update your storage planning baselines and any compliance or eDiscovery configurations that assume a 50 GB ceiling.

Useful context when building business cases for consolidating workload protection onto the Microsoft stack.

- **[Turn conversations into code with GitHub Copilot in Microsoft Teams](https://techcommunity.microsoft.com/t5/microsoft-teams-blog/turn-conversations-into-code-with-github-copilot-in-microsoft/ba-p/4548305)** [GA] - GitHub Copilot is now available inside Teams, letting developers @mention it in a channel conversation to convert the discussion context directly into code without switching tools. - **[Planner: Microsoft Planner tab support for shared and private channels in Microsoft Teams](https://www.microsoft.com/microsoft-365/roadmap?id=558928)** [GA] - Planner tabs can now be added to shared and private Teams channels, not just standard channels. This closes a gap that previously forced teams to use workarounds for task management in sensitive project channels. Rolling out August 2026.

- **[Microsoft Teams: Digital signage support for Teams panels](https://www.microsoft.com/microsoft-365/roadmap?id=558852)** [GA] - Idle Teams panel devices can now display digital signage, matching the capability already available on Teams Rooms front-of-room displays. This shipped July 2026 and is worth a governance conversation if your organization wants to enforce consistent project structures.

- **[Planner: Capacity view](https://www.microsoft.com/microsoft-365/roadmap?id=569733)** [GA] - A new Capacity view in Planner shows a timeline of task assignments across team members, making it easier to spot overloaded individuals or idle capacity at a glance. Targeting October 2026 GA.

- **[Microsoft Teams: Coordinated meetings support on Teams Rooms on Android](https://www.microsoft.com/microsoft-365/roadmap?id=569420)** [GA] - Teams Rooms on Android devices and Android-based touch boards can now coordinate join, leave, and collaboration actions in the same hybrid meeting. Targeting January 2027. Relevant for facilities teams planning Android-based meeting room deployments.

## Endpoint & Device Management

- **[Steal A Table Out Of An Image](https://www.youtube.com/shorts/KykT5uUezOE)** [GA] - On Windows 365 Cloud PCs with at least 8 vCPUs, the Click to Do feature (Windows key + Q) can extract text from non-selectable graphical images, including tables, and paste the data directly into Excel as live, editable content. This capability is available now on AI-enabled Cloud PCs and is worth surfacing to productivity-focused user groups.

- **[That App Isn't Native. It's Windows.](https://www.youtube.com/shorts/rRA8lVyALO8)** [GA] - Windows 365 Cloud Apps with Windows 365 Flex publishes individual Windows applications from a shared Cloud PC pool, presenting them full-screen on tablets as if they were native mobile apps, with settings and files roaming with the user. This is a meaningful shift in how you can deliver Windows line-of-business apps to non-Windows devices without provisioning a full dedicated Cloud PC per user.

- **[Zero Cloud Tokens To Build And Run This App](https://www.youtube.com/shorts/dJDlftFFj28)** [GA] - Developer Optimized Windows 365 Cloud PCs running Foundry Local can execute Phi-4-mini entirely on local compute, confirmed via Task Manager NPU/CPU profiling in VS Code. This matters for environments where data sovereignty or cost controls restrict cloud AI API usage during development.

- **[Why Only One Region Had Bad Connections](https://www.youtube.com/shorts/M7yRVvRzQvs)** [Preview] - The Windows 365 admin agent, now in preview, accepts natural-language queries and correlates session telemetry across regional cohorts to surface root causes. The demo scenario identified TCP-only transport (missing UDP/RDP Shortpath) as the culprit for localized connection degradation. Worth evaluating in your tenant if you manage large Windows 365 deployments and want faster root-cause analysis.

- **[No Windows 365 On My Phone. Still Works.](https://www.youtube.com/shorts/ueoaivM5B8k)** [GA] - Microsoft Scout can interact with a Windows 365 Cloud PC from a Teams chat on a mobile device, accessing files and apps on the Cloud PC without the Windows 365 client installed on the phone. This extends Cloud PC utility to scenarios where users are away from their primary device and demonstrates the agentic capability model built on the open-source OpenClaw project.

- **[Scout Did This With My Laptop Closed](https://www.youtube.com/shorts/1wrVbE3NYW8)** [GA] - Microsoft Scout located a report in a Cloud PC's Downloads folder (not synced to OneDrive), appended a summary, saved the file, and staged a draft email with the attachment in Outlook, all triggered from a Teams chat on a phone. Demonstrates practical agentic file handling for Cloud PC users who need async task completion.

- **[Windows 365: Five Years In, See What's New](https://www.youtube.com/watch?v=MK-hCq7Su1w)** [GA] - A comprehensive overview of the current Windows 365 capability set: Microsoft Scout agentic workflows, Developer Optimized Cloud PCs with Foundry Local for local AI inference, Windows 365 Flex for shared Cloud PC pools and published apps, and the new admin agent in preview. Share with stakeholders evaluating Cloud PC investment or planning fiscal year licensing reviews.

- **[Task Manager features for visibility into AI workloads](https://techcommunity.microsoft.com/t5/windows-it-pro-blog/task-manager-features-for-visibility-into-ai-workloads/ba-p/4545150)** [GA] - Task Manager now shows per-process NPU and GPU neural engine activity on supported newer devices, alongside existing CPU and GPU metrics, giving IT pros a native tool for troubleshooting AI workload performance without third-party utilities. Useful for validating NPU utilization on Copilot+ PCs and Developer Optimized Cloud PCs.

- **[Collecting Delivery Optimization logs the easy way](https://techcommunity.microsoft.com/t5/windows-it-pro-blog/collecting-delivery-optimization-logs-the-easy-way/ba-p/4547884)** [GA] - The Windows IT Pro team documents a free tool for collecting Delivery Optimization and Connected Cache logs, covering scenarios where peering efficiency is low or content is bypassing a Connected Cache node. Bookmark this for your next Patch Tuesday troubleshooting cycle; it significantly simplifies log collection before engaging Microsoft support.
