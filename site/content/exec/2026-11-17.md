## The Week at a Glance

- 🔴 **AI agents are acquiring organizational identities and acting unsupervised, and most organizations have no governance in place for them:** Copilot Studio agents can now hold Microsoft 365 accounts, join Teams, send email, and take autonomous action across your systems; Microsoft's own data shows 29% of employees are already using unsanctioned agents, and 32% of organizations have experienced a data security incident involving generative AI.

Exchange Online customers are not affected.

- 🟢 **Intune adds CIS benchmark auditing for Windows 11 in preview:** Organizations can now audit device configurations against the Center for Internet Security benchmark, surfacing compliance gaps without changing any settings; relevant groundwork for CMMC, HIPAA, and SOC 2 frameworks.

## Why This Week Matters

Ahead of Microsoft Ignite 2026, a question is landing on leadership teams: as AI agents take on autonomous action across your organization, do you know what they can access, what they can do, and who is accountable when something goes wrong? This week's updates combine guidance on agent governance, research on supply chain attacks against coding agents, threat campaigns abusing remote access tooling, and new compliance auditing for Windows, so the decisions sit at the intersection of AI strategy, security posture, and regulatory readiness.

## Risk & Compliance

- 🔴 **[AI agents with organizational identities require governance now](https://techcommunity.microsoft.com/t5/copilot-studio-blog/where-do-i-govern-my-copilot-studio-agents/ba-p/4572592):** {{< emphasis "AI" >}} {{< emphasis "Identity" >}} Copilot Studio agents can now hold M365 accounts, join Teams, and act autonomously across systems, yet Microsoft's data shows nearly one-third of organizations have already experienced a generative AI data security incident; this gap is directly relevant to SOC 2, HIPAA, and CMMC access-control requirements, and the window to establish governance before incidents occur is closing.

- 🔴 **[SCKit abuses ScreenConnect to deploy remote access and target technician sessions](https://www.microsoft.com/en-us/security/blog/2026/11/13/sckit-abuses-screenconnect-deploy-remote-access-target-technician-sessions/):** {{< emphasis "SecOps" >}} An active threat actor is weaponizing remote support tooling to establish persistent unauthorized access through the accounts and sessions that your IT team trusts most, closing this implicit-trust gap requires immediate review of which remote access tools are authorized and how technician sessions are protected; relevant to cyber insurance breach-notification triggers.

- 🔴 **[November 2026 Exchange Server Security Updates](https://techcommunity.microsoft.com/t5/exchange-team-blog/released-november-2026-exchange-server-security-updates/ba-p/4570368):** Unpatched on-premises Exchange servers carry known, publicly disclosed vulnerabilities as of this week; organizations under HIPAA, CMMC, or SOC 2 obligations have a narrow window to patch before auditors and attackers treat the gap the same way.

- 🟡 **[AI supply chain attacks targeting coding agents via poisoned models](https://www.microsoft.com/en-us/security/blog/2026/11/12/trained-to-betray-how-post-training-supply-chain-attacks-hijack-coding-agents/):** {{< emphasis "AI" >}} {{< emphasis "SecOps" >}} Microsoft's research confirms that compromised AI models can trigger remote code execution through developer tooling; organizations using AI coding assistants or integrating third-party AI models should inventory those dependencies and validate sourcing within 30 days.

- 🟡 **[Trusted-identity attacks targeting AI assets, including GitHub Copilot CLI](https://learn.microsoft.com/en-us/defender-cloud-apps/protect-github):** {{< emphasis "AI" >}} {{< emphasis "Identity" >}} Device code phishing attacks are now specifically designed to compromise AI agents by exploiting the trusted identities they run under, strengthening verification for developer and agent service accounts is a concrete Zero Trust improvement available now in Defender XDR preview.

- 🟡 **[GSocket deployed for stealthy persistent access on Linux servers](https://www.microsoft.com/en-us/security/blog/2026/11/11/global-socket-how-threat-actors-weaponizing-gsocket-stealthy-c2/):** {{< emphasis "Infrastructure" >}} Threat actors are planting encrypted remote-access backdoors on Linux infrastructure that survive patching; organizations running Linux workloads in hybrid or cloud environments should validate their detection coverage, particularly relevant to NIST CSF Detect and Respond functions.

- 🟡 **[Microsoft data governance strategy moves natively into Microsoft Fabric](https://techcommunity.microsoft.com/t5/microsoft-security-community/a-next-step-in-the-evolution-of-the-microsoft-data-governance/ba-p/4572227):** {{< emphasis "Data" >}} Microsoft is consolidating data governance into the Fabric platform via the OneLake catalog, which will affect how organizations using Purview as a standalone governance layer manage their data classification and lineage programs; teams with active Purview data governance deployments should evaluate the transition timeline.

- 🟡 **[New authentication governance controls for Power Pages](https://www.microsoft.com/en-us/power-platform/blog/power-pages/new-authentication-governance-controls-in-power-pages/):** {{< emphasis "Identity" >}} Administrators can now restrict which authentication providers and OAuth identity protocols are permitted on Power Pages sites; organizations running customer-facing or partner portals on Power Pages should review allowed authentication methods to close unnecessary access paths.

- 🟢 **[CIS benchmark auditing for Windows 11 devices in preview](https://learn.microsoft.com/en-us/intune/device-security/security-baselines/cis-audit-baseline):** Organizations can now audit Windows 11 devices against the CIS Intune benchmark without changing any settings, surfacing configuration gaps relevant to CMMC, HIPAA, and SOC 2 technical safeguard requirements; this requires Microsoft Intune Advanced Analytics licensing.

- 🟢 **[Work file download controls enforced to OneDrive for Business via Edge](https://learn.microsoft.com/en-us/intune/app-management/protection/ref-settings-windows#data-transfer):** Intune can now enforce that work files downloaded via Edge for Business land in OneDrive rather than local disk, reducing the risk of organizational data residing on unmanaged or personal storage and supporting data-residency compliance requirements.

## What Your Employees Will Notice

- **AI agents appearing as colleagues:** Employees may start seeing Copilot Studio agents listed in Teams and Outlook with their own profiles and org-chart entries. Proactive communication about which agents are sanctioned, what they are authorized to do, and how to report unexpected behavior will reduce confusion and shadow-AI use.

- **Edge for Business file downloads redirected:** On managed Windows devices, employees using the Edge work profile may find that files they download land in OneDrive for Business rather than their local Downloads folder. Brief communication ahead of rollout will prevent help desk calls.

- **Remote Help diagnostic sharing prompts:** Employees receiving IT support via Remote Help on Windows will see a new consent prompt asking whether they agree to share device diagnostics. The prompt is optional and declining it does not end the support session.

- **macOS devices receiving apps and policies faster after enrollment:** Newly enrolled Mac users will see apps and configurations appear much sooner than before, reducing the gap between device pickup and a fully configured, work-ready machine.

- **Windows update activity more predictable:** With maintenance windows now available for OS and driver updates, employees in organizations that configure this feature will experience update-related restarts within planned windows rather than at unpredictable times.

## What Your Help Desk Should Expect

- **Increase in AI agent access and behavior questions:** As agents appear in Teams and Outlook with organizational identities, employees and managers will ask who authorized them, what they can do, and how to remove or report one. Help desk teams need a clear escalation path before this question volume arrives.

- **File-not-in-Downloads-folder tickets:** Employees on the new Edge for Business download policy will generate tickets when they cannot locate files they expected on the local disk; a brief one-line FAQ entry should resolve most of these.

- **Remote Help diagnostic consent confusion:** Some users will be unsure whether accepting the diagnostic-sharing prompt is required or optional. Help desk staff should know the prompt is optional and consent or refusal does not affect their ability to get support.

- **Exchange Server patching follow-up:** If your organization runs on-premises Exchange, the security update process may require a service window and generate tickets if mail flow is interrupted during patching.

- **Driver update inconsistency questions from IT staff:** The published support tip on Windows driver recommendations varying across deployment rings explains expected behavior; sharing this with endpoint management staff now will prevent unnecessary escalations.

## Cost & Licensing

- **CIS benchmark auditing requires Intune Advanced Analytics:** The new Windows 11 CIS audit capability is gated behind the Microsoft Intune Advanced Analytics add-on. Organizations currently on standard Intune licensing who want to use this feature for CMMC, HIPAA, or SOC 2 compliance evidence should budget for this add-on before treating it as an available tool.

- **Agent identity accounts carry licensing implications:** Copilot Studio agents that hold M365 accounts, join Teams, and send email through organizational mailboxes may require additional Microsoft 365 or Copilot licensing per agent, depending on the services they access. Finance and IT leadership should audit agent account provisioning against current license agreements before broad deployment.

- **Power Platform monitoring alert frequency:** Hourly alerting in Power Platform Monitor is now generally available at no additional cost tier change, but organizations not yet using Monitor for their Power Apps and flow environments should factor operational staffing into the value assessment.

## If You Take No Action

**AI agents operate without governance or accountability.** Microsoft's data shows 29% of employees are already using unsanctioned AI agents. Without an inventory, approval process, and access policy in place, your organization is accruing data security incidents it cannot see, cannot attribute, and may not be able to explain to regulators under SOC 2, HIPAA, or state privacy law obligations.

**Unpatched Exchange Server becomes an active liability.** Security updates released this week address vulnerabilities that are now publicly disclosed. Every day an on-premises Exchange server runs without these patches, it represents a known attack surface. Organizations under HIPAA or CMMC face compounding risk: a successful breach on unpatched infrastructure is both a security failure and a compliance event.

**ScreenConnect-based attacks escalate undetected.** The SCKit campaign is specifically designed to compromise the technician accounts and sessions that carry the highest implicit trust in your environment. Without reviewing session controls and validating detection coverage now, the most privileged access path in your IT operations remains exposed to an active, documented threat.
